# 结构化图第二批：类图 / 用例图 / 排期图

## Status

accepted（ADR-0009 的继续）

## 决定

在 mermaid 子集之上再加三种图，全部自己解析、输出内联 SVG、失败即退回代码块：

| 图型 | 首行 / 语言标记 | 支持的语法 |
| --- | --- | --- |
| **类图** | `classDiagram` | `class X { ... }` 成员块、裸类名；关系 `<\|--`（继承）、`<\|..`（实现）、`*--`（组合）、`o--`（聚合）、`-->`、`..>`，两端可带基数 `"1"` / `"*"`，可带 `: 标签` |
| **用例图** | `usecaseDiagram`，或代码块语言 `usecase` | `actor 名称`、`usecase 名称`、`A --> B` |
| **排期图** | `gantt` | `title`、`dateFormat YYYY-MM-DD`（必填）、`section`、任务行 `名称 :[id,] [after id \| 日期,] 工期`，工期 `Nd` / `Nw` |

**用例图是本项目扩展**：mermaid 没有原生用例图语法。为避免在 mermaid 生态里制造"看起来合法但只有我们知道"的语法，它用独立语言标记 `usecase`（GitHub 上显示为代码块，不会报错），同时也接受 ```` ```mermaid ```` + `usecaseDiagram` 首行。

## 为什么

- 这三种是"读者收益 / 实现成本"最高的一批：类图与用例图**复用已有的分层布局**，不需要新的布局引擎；排期图的时间轴布局是独立的、但公式很浅。
- 类图的边带语义（继承 / 实现 / 组合 / 聚合 / 依赖），所以必须用不同 marker 区分——只用一种箭头会把"继承"画成"调用"，那是**语义错误**，比画得丑严重得多。
- 排期图强制要求 `dateFormat`：mermaid 允许省略，但省略后日期语义依赖浏览器/地区，确定性输出（ADR-0002）要求写死。写不出来就退回代码块。

## Considered Options

- **给用例图也用 mermaid 首行**：会让 mermaid 用户在 GitHub 上看到语法错误。改用独立语言标记，两种入口都支持。
- **类图用流程图渲染器**：它的节点只有一行文字，装不下成员列表；因此单独写了带标题带 + 成员区的类框，但**共用 `layerize` 分层**。
- **排期图支持 `axisFormat` / `tickInterval` / `excludes`**：都是渲染细节，收益低；不支持时整块退回，不留半成品。
- **不支持 `after` 依赖**：会让"方案设计"这类任务无法表达相对排期，是真实需求。已支持，并做了成环检测（环 → 整体退回）。

## Consequences

- 类图 marker 需要新的 SVG 定义：空心三角（继承/实现）、实心菱形（组合）、空心菱形（聚合）。已加进 `svg.mjs` 的 `MARKERS`，颜色仍走变量。
- 排期图的月份刻度做了一处修正：起点所在月份若月初早于最早任务，刻度画在最早任务处，否则轴上会缺第一个月（实测发现）。
- 用例图的 actor 用极简线条人形（圆 + 四点线），不用 emoji、不用图标字体（craft floor 的禁令）。
- 三种图都与既有约束一致：文字仍是 `<text>`、无外链、无脚本、颜色来自变量、产物确定性。
- 仍未支持：活动图/泳道图、C4、部署图、依赖图、思维导图、Git 分支图。它们各自需要新布局（泳道 / 嵌套框 / 时间轴变体），按需再加。

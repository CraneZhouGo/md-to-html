# 视觉世界：工程文档模板（用户钉住）

## Status

accepted（取代 ADR-0004 中与本文件冲突的条款）

## 决定

采用用户提供的 `ai-coding-document-template.html` 作为本项目的视觉世界。已按该模板完整实现一版真实产出：`templates/g-engineering.html`（真内容取自 `.scratch/html-vs-md/research.md`，可直接双击对比）。

**采纳（照原样）**

- 三列布局：顶栏 60px + 左导航 252px + 正文 800px + 右目录 220px；断点 1180 / 900 / 520。
- 色彩：`--bg #f7f8fa`、`--surface #fff`、`--text #182230`、`--accent #5268e8`，深色为 `#0d1117 / #9aa7ff`；全部走 CSS 变量，`html[data-theme]` 切换。
- 组件语言：胶囊标签、信息卡、提示块（i / ! / ×）、圆角 10px 带边框表格（zebra 行）、深色代码块 + 复制按钮、`blockquote` 左侧 3px 强调条。
- 交互：顶栏搜索（回车跳到下一处匹配并高亮）、主题切换、阅读进度条、移动端抽屉导航、自动生成的右侧目录。
- 字体栈以 `Inter` 起头但**没有** `@font-face`，实际回退系统字体 —— 与"零网络字体"一致。

**改写（保留风格，换掉其中的功能）**

| 模板里的东西 | 改成 | 依据 |
|---|---|---|
| 顶栏 `↓ PDF` 打印按钮 + `@media print` 整套 | 顶栏 `↓ 原始 .md` 出口，删除全部打印样式 | ADR-0004 已取消打印；需要纸面稿的人拿 markdown |
| 正文 15px | **16px**（行高 1.78） | 中文在 15px 偏小；16px 在 800px 列宽下约 50 字/行，仍在舒适区 |
| 正文列 820px | 800px | 与 16px 字号配比 |
| `IntersectionObserver` 做目录高亮 | `scroll` + `getBoundingClientRect().top <= 88` + `requestAnimationFrame` 节流 | ADR-0004：实测 4/4 范本都用滚动数学，且它在锚点跳转、打印、无 JS 场景下更可控 |
| 硬编码的左侧导航条目 | 由正文 `h2` 生成 | 导航不得成为第二份内容（ADR-0006 的"文字必须来自真源"） |
| `localStorage` 键 `doc-theme` | `md2h-theme` | 与 ADR-0005 的命名空间要求一致 |

**拒绝（不随风格一起接受）**

- 模板里的 `{{DOC_TITLE}}` 等占位符机制：本项目的产物由真源确定性生成，不引入第二套模板语法。
- 模板允许"用示例正文替换"的做法：本仓库的产物必须由渲染器直接从 markdown 产出，不手工拼装。

## 为什么

用户钉住了这个方向，钉住的方向永远胜过掷骰结果。它同时解决了前三版都没解决的问题：既清爽（浅底、单一强调色、发丝线、无装饰插画），又带科技感（等宽标签、进度条、目录高亮、深色代码块），而且科技感来自**信息结构**而不是发光与渐变。

这个模板此前已在真实工程文档里被验证过一遍（自带边界情况清单：超长标题、长 URL、宽表格、超长代码行、键盘导航、明暗主题、插件失败降级），把它当作起点比自己重新发明一套组件语言更省风险。

## Consequences

- ADR-0004 的以下条款被本 ADR 取代：正文 17px / 行高 1.75 / 780px、右侧**单栏浮动**目录（现在是三列常驻）、"不做进度条"、以及"不引入卡片"的装饰预算。其余条款（对比度 ≥10:1、系统字体栈、原生 `<details>`、代码块规格、超宽内容横向滚动、零 `@media print`）继续有效。
- 三列布局的代价是窄屏（<900px）同时丢掉左导航与右目录，此时长文只能靠顶栏；这是该风格的固有取舍，接受。
- 视觉 token 必须继续集中在 `:root`，个性化（ADR-0005）只覆盖变量：已验证可以只改 `--accent` / `--content` / 字号三个变量而结构不动。
- 该模板的组件清单（pill / info-card / callout / blockquote / table / pre）即为渲染器的完整输出面；markdown 元素到组件的映射关系需在渲染器里逐条落定，尤其：`> 引用` → `blockquote`，`::: callout` 或首词判定 → `callout`，表格 → 圆角表。
- 顶栏品牌区（`M` 方块 + `md-to-html`）为固定标识，不做个性化，避免产物上出现个人身份（ADR-0005）。
